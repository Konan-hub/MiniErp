# MiniErp - Core Textile ERP Simulation

A lightweight, production-ready Java 21 application designed to simulate core Enterprise Resource Planning (ERP) workflows. This project focuses on heavy raw data parsing, stock management, and strict Clean Code principles, mirroring modern ERP challenges like data integration and legacy system synchronization.

## 🚀 Key Features (In Development)
* **Master Data Management (MDM):** Robust parsing and encapsulation of raw material and article data strings.
* **Inventory Control:** Core services to handle stock adjustments, filtering, and valuation.
* **Clean Architecture:** Strict separation of concerns using a layered package structure (`model`, `service`, `app`).

## 🛠️ Tech Stack & Technical Specifications
* **Language:** Java 21
* **Design Patterns & Concepts:** Object-Oriented Programming, Encapsulation, Data Cleansing (String splitting/parsing).
* **Code Quality:** Single Responsibility Principle (SRP), meaningful naming conventions, self-documenting code.
* **Version Control:** Git & GitHub using conventional commit messages.
